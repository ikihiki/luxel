## Release 1.0.0

### New Rules

Rule ID | Category | Severity | Notes
--------|----------|----------|------
NGUI001 | Luxel.UI | Warning | Widget types with generated UI members must be partial
NGUI002 | Luxel.UI | Warning | UI components should use generated constructors
NGUI003 | Luxel.UI | Error | Reactive layout utilities are not supported
NGUI004 | Luxel.UI | Error | Layout utilities cannot target visual states
NGUI005 | Luxel.UI | Error | Utility targets must match the component type
