PhysicsSettings

class — PhysicsWorld の生成時設定。既定値は「1 ユニット = 1m、60Hz 固定ステップ、単スレッド」。 単スレッド (ThreadCount = 0) は**決定的** — snap 回帰 (golden) と同じ思想で、 同じ初期状態 + 同じステップ列は常に同じ結果になる。ThreadCount > 0 は速いが決定性を失う (opt-in)。

コンストラクタ

名前型説明

フィールド

名前型説明

FixedDtfloat固定タイムステップ (秒)。Single) の accumulator がこの刻みで進める。
LinearDampingfloat速度の減衰 (0..1/秒相当)。空気抵抗の近似。

PhysicsStepSystem

class — ECS と PhysicsWorld のブリッジ (毎フレーム 1 回): Attach — 未発行の Collider + RigidBody/StaticBody entity に body/static を発行 (初期 pose は LocalTransform の分解から) Step — 固定タイムステップ accumulator (Single)) Write-back — 動的ボディの pose を LocalTransform = Scale(RenderScale) × Rotation × Translation で書き戻す 書き戻し後は既存の流れ (TransformPropagateSystem → Render3DExtractSystem) がそのまま描く。 ScheduleRoot に載せる場合の規約位置は Update。 制約 (v1): Parent 付き entity の RigidBody は未定義動作 (物理はワールド空間)。 entity 削除に連動した body 削除は行わない — リセットは World + PhysicsWorld の丸ごと再構築で (決定的な初期状態に戻る正攻法)。

コンストラクタ

名前型説明
PhysicsStepSystem(World world, PhysicsWorld physics)

メソッド

名前型説明
Run(float dt) → int手動駆動 (デモ/テスト用)。dt は経過秒 — 内部で固定ステップへ分割される。実行ステップ数を返す。
StepFixedOnce() → voidFixedUpdate フェーズから駆動する用: 固定 dt で**必ず 1 ステップ**進める (蓄積は GameScene 側に一本化されている前提)。

PhysicsWorld

class — BepuPhysics v2 の薄いラッパ — Simulation/BufferPool の生成/破棄と callbacks boilerplate を隠蔽し、固定タイムステップの accumulator を提供する。 決定性: 既定 (ThreadCount = 0 = 単スレッド) では、同じ初期状態 + 同じステップ列は 常に同じ結果になる — snap 回帰 (固定 1/60s ステップ) と両立する。マルチスレッドは opt-in で、 速い代わりに決定性を失う。 使い方: using var physics = new PhysicsWorld(); var floor = physics.AddStatic(new RigidPose(new Vector3(0, -0.5f, 0)), physics.AddShape(new Box(8, 1, 8))); var box = physics.AddDynamic(new RigidPose(new Vector3(0, 3, 0)), new Box(1, 1, 1), mass: 1); physics.Step(dt); // 毎フレーム (固定 dt へ分割される) RigidPose pose = physics.GetPose(box); // 描画へ反映 ECS で使う場合は PhysicsStepSystem が Attach/Step/書き戻しを担う。

コンストラクタ

名前型説明
PhysicsWorld(PhysicsSettings settings)

メソッド

名前型説明
Step(float elapsed) → int経過時間を accumulator へ積み、固定 FixedDt で進める (実行ステップ数を返す)。 巨大な elapsed は 0.25s に clamp — 停止からの復帰でスパイラルしない。
StepOnce() → void固定 dt で 1 ステップだけ進める (テスト/手動駆動用)。
AddShape(TShape shape) → TypedIndexshape を登録して bindless 的な TypedIndex を得る (同じ形は使い回してよい)。
AddDynamic(RigidPose pose, TShape shape, float mass, BodyVelocity velocity, float sleepThreshold, bool continuous, float maxSpeculativeMargin) → BodyHandle動的ボディを追加する (慣性は shape × mass から計算)。 = true で CCD (連続衝突検出) を有効化 — 高速な物体が薄い壁を すり抜けるトンネリングを防ぐ (掃引コストと引き換え)。既定 false は Bepu の Passive (discrete)。 は投機的接触の生成距離上限。既定 (無制限) では Bepu は速度に応じた投機マージンで大抵のトンネリングを discrete でも防ぐ — CCD が本当に効くのは この値を絞った (薄い壁 + 極端な速度) 場合や回転を伴う掃引。
AddStatic(RigidPose pose, TypedIndex shape) → StaticHandle静的コライダーを追加する (床/壁)。
AddTrigger(RigidPose pose, TypedIndex shape) → StaticHandleトリガーボリュームを追加する — 物理応答なしで通過だけを検知する静的 collidable。 動的ボディがこの形状に触れると ContactEvents に Begin/End が出るが、力は働かない。
AddMeshShape(ReadOnlySpan<Vector3> vertices, ReadOnlySpan<int> indices, Vector3 scale) → TypedIndex三角形スープ (頂点 + インデックス) から静的メッシュ shape を登録する (地形/建物など)。 Bepu Mesh は BufferPool のメモリを保持するが、Simulation の Shapes 経由で 追加するため Dispose 時に解放される。動的メッシュは非対応 (動的は Boolean))。
AddStaticMesh(RigidPose pose, ReadOnlySpan<Vector3> vertices, ReadOnlySpan<int> indices, Vector3 scale) → StaticHandle静的メッシュコライダーを追加する (三角形スープ直渡し)。
AddDynamicHull(RigidPose originPose, Span<Vector3> points, float mass, Vector3 center, BodyVelocity velocity, float sleepThreshold, bool continuous) → BodyHandle頂点群から凸包 (ConvexHull) の動的ボディを追加する。 Bepu は形状を重心原点へ recenter するため (入力座標系での重心) を返す — は「入力頂点の原点」を指す pose として渡し、内部で重心ぶん平行移動して発行する (描画メッシュとの位置合わせは GetPose - Rotate(center) で元の原点に戻す)。
AddKinematic(RigidPose pose, TypedIndex shape) → BodyHandleキネマティックボディを追加する (スクリプト駆動で動く的/プラットフォーム)。無限質量で 外力に動じず、RigidPose@) で毎ステップ姿勢を与える。動的ボディの CCD は静的同様に確実に当たる。
SetBodyPose(BodyHandle handle, RigidPose pose) → voidボディの姿勢を直接設定して起こす (キネマティックの scripted 移動用)。
RemoveBody(BodyHandle handle) → void動的ボディを削除する (despawn / kill plane 用)。ECS 側の entity 削除と対で呼ぶ — entity だけ消して body を残すと「見えない衝突体」がリークする。
RemoveStatic(StaticHandle handle) → void静的コライダーを削除する。
GetPose(BodyHandle handle) → RigidPoseボディの現在 pose (位置 + 回転)。
IsAwake(BodyHandle handle) → boolボディが起きているか (静止すると sleep して false)。
RayCast(Vector3 origin, Vector3 direction, float maximumT, PhysicsRayHit hit) → bool最近傍レイキャスト。ヒットが無ければ false。
Dispose() → void
