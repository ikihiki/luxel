FixedTimestep

class — 固定タイムステップの蓄積器。可変 dt を積み、固定刻み FixedDt ごとに FixedUpdate を何回回すかを決める (フレームレート非依存の決定的シミュレーションの土台)。 spiral of death 防止: 1 フレームの実行回数は MaxStepsPerFrame で頭打ち。 超過した余剰時間は**捨てる** (スローモーション化を避ける) — 捨てた分は DroppedSteps に計上する。 描画補間: Alpha は「次の固定ステップまでの進捗 [0,1)」。 Render 時に lerp(prevState, currState, Alpha) すると 60Hz 表示 + 1/60 固定でもガタつかない。 浮動小数の蓄積誤差を避けるため内部は double で持つ (0.1×n の累積で割れる前例あり)。 GPU 非依存 — 単体テスト可能 (core 常駐)。

UiSurface

class — 独立した描画対象 (UI パネル / モニタ / 低解像度 3D レイヤ等)。GameScene に UiSurface) で登録すると、per-frame で RateHz に従って Draw callback が RenderGraph 内の 1 pass として実行される。 rate 制御 (Option A: 時間ベース throttle): RateHz &gt; 0: 目標更新頻度。(now - lastRendered) &gt;= 1/RateHz のとき描画 RateHz == 0: 毎フレーム描画 RateHz &lt; 0: NeedsRedraw が true のときだけ描画 Option B (表示 rate の整数分の 1) は本仕組みの上で実現: 表示が 60Hz なら RateHz = 30 で毎 2 フレームに 1 回、RateHz = 15 で毎 4 フレームに 1 回、 と時間軸で整数分の 1 に自然に落ちる (float 誤差 1e-6 で吸収)。 用途例: HUD: RateHz = 60, Kind = ScreenSpaceOverlay コクピット計器 (10 Hz 更新で十分): RateHz = 10, Kind = WorldSpaceQuad ダメージパネル (状態変化時のみ): RateHz = -1, dirty flag で駆動 3D 低解像度レイヤ (30Hz → upscale): RateHz = 30, Kind = ScreenSpaceOverlay (低解像度 Target)
