GltfBufferStep

class — foo.glb#mesh/N/vertex、foo.glb#mesh/N/index、foo.glb#materials のような URI を処理する GpuBuffer プロバイダ。N は SceneAssets.OrderedPrimitives の index (primitive の登場順、SceneBuilder が確定)。

コンストラクタ

名前型説明
GltfBufferStep(GpuDevice device)foo.glb#mesh/N/vertex、foo.glb#mesh/N/index、foo.glb#materials のような URI を処理する GpuBuffer プロバイダ。N は SceneAssets.OrderedPrimitives の index (primitive の登場順、SceneBuilder が確定)。

メソッド

名前型説明
RunAsync(SceneAssets assets, ResourceUri uri, LoadContext ctx) → Task<GpuBuffer>fragment に応じて vertex/index buffer (borrowed) または materials buffer (owned) を返す。

プロパティ

名前型説明
ExecutorExecutor (get)GPU executor で実行 (buffer 確保のため)。
FragmentPatternsIEnumerable<string> (get)処理対象の fragment パターン。

GltfLoader

class — glTF 2.0 (.gltf / .glb) を AssetDocument (direct-ref モデル) に変換する loader。 glTF は index 参照だが、loader 内で 2 pass 走査し「オブジェクト作成 → 参照解決」してから返す。

コンストラクタ

名前型説明
GltfLoader()

メソッド

名前型説明
CanLoad(string path) → bool拡張子 .gltf / .glb を受け付ける。
LoadAsync(string path) → Task<AssetDocument>ファイルを読み込み AssetDocument に変換。外部 .bin / 画像 / data:URI も解決する。

GltfStep

class — ResourceSystem 統合用 step。 .gltf/.glb ファイルの byte[] を受け取り、AssetDocument に変換。 外部 .bin / 画像は String) で自動キャッシュ取得 (Resources の dependency graph に組込まれる)。

MaterialTextureStep

class — foo.glb#material/N/baseColor で SceneAssets 内の baseColor texture を borrowed 取得する step。 N は MaterialArray の index。

コンストラクタ

名前型説明
MaterialTextureStep()

メソッド

名前型説明
RunAsync(SceneAssets assets, ResourceUri uri, LoadContext ctx) → Task<GpuTexture>fragment で指定された material の baseColor texture を borrowed で返す。

プロパティ

名前型説明
