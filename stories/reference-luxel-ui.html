CompositeControl

class — 既存コントロールを**宣言的に組み合わせる**複合コントロールの基底。 Build が返したサブツリーへレイアウト/実体化を委譲する — PerformLayout/RealizeCore は書かない (完全自前描画が要るときは従来どおり Widget 直接派生)。 状態の 3 層 (規約): - 外部 props = [UiParam] Bindable フィールド (呼び出し側/knobs が束縛) - 内部の値状態 = private Signal — Bindable/getter で子へ配線し細粒度反映 (Rebuild 不要) - 内部の構造状態 = フィールド — 変更したら Rebuild (明示) **状態を保ちたい子コントロールはフィールドに保持し、Build ではその参照を組み込むこと** — Rebuild で作り直されるのはコンテナ (StackPanel 等、状態なし) だけで、子インスタンスは生き残る。
