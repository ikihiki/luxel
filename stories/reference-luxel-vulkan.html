VulkanBackend

class — Vulkan 1.3 バックエンド。「No Graphics API」設計の薄いラッパー。 全パイプライン共通の固定レイアウト: set 0 / binding 0 = bindless storage buffer 配列 (descriptor-indexing) push 定数 (192B) = ルート引数 シェーダは g_buffers[index] でバッファを参照する (D3D12 と同一の index モデル)。

VulkanPresentationMode

enum — Vulkan バックエンド初期化時の presentation 構成。

値

名前型説明
AutoWindows では Win32 presentation、それ以外では headless を選ぶ。
