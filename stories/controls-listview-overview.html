Controls/ListView/Overview

ListView

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

文字列行のリスト (固定行高、ホイール + サムでスクロール、クリック選択)。**仮想化 (AP-M3)**: 実体化するノードは可視行数 + 1 の固定プールだけで、スクロール/ 差し替えは プールへの**再バインド** (Content 再代入 = canvas の in-place 部分更新) — ノード数は行数にも スクロールにも依存せず、構造 dirty は発生しない (10 万行でもノードは数十個)。 スクロール位置はフィールドなので再実体化をまたいで生き残る。 行ごとに Effect は作らない — 色は Realize 時の単一 Effect が全行へ流す。

イベント

名前型説明
OnSelectUiEvent<ListView, int>行クリックで呼ばれる (index)。(EV: 第一引数は発火元の ListView 自身)
OnReorderUiEvent<ListView, int, int>並べ替えドロップ (from 行, 挿入先 index — from 除去**前**の位置)。
