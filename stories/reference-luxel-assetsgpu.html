AssetGpuRegistry

class — Asset* を GPU へ upload + cache する service。ResourceSystem の DI 経由で Step が受け取って利用する (通常は user コードは Step 経由で間接的にアクセス)。 セットアップ: プログラム起動時に registry を作って DI に登録し、必要な Step を追加する。 var registry = new AssetGpuRegistry(device); resources.AddService(registry); resources.AddStep&lt;AssetMeshToGpuStep&gt;(); // ctor で (GpuDevice, AssetGpuRegistry) を受け取る resources.AddStep&lt;AssetMaterialToGpuStep&gt;(); resources.AddStep&lt;AssetTextureToGpuStep&gt;(); Resource system を使わない場合は GpuAssetFactory を直接呼んで sample 側で Dictionary を管理する。

RenderBuffer

class — CPU 側 staging (T[]) + GPU 側 GpuBuffer (HostMapped) のペア。 Data を書き換えて MarkDirty すると次の Pump で GPU に反映される。 Resources 経由で publish されると、cross-pass で同じ buffer を共有できる (RGRE-M2a)。 値そのもの (RenderBuffer 参照) は不変 ─ 消費側は Buffer を rg.ImportBuffer で毎フレーム取り込む。 内部の staging → GPU 反映と Reloaded 伝播は Pump が1回で行う。

コンストラクタ

RenderTarget

class — 差替可能な GPU テクスチャ。RG が毎フレーム描画結果を書き込む先として使い、 Resources 経由で他コンポーネント (別 RG / UI / thumbnail) が最新テクスチャを引ける (RGRE-M2a)。 テクスチャ本体 (Texture) は解像度変更が必要な場合のみ差し替わる。 描画完了通知は Reloaded を通じて Pump で伝播する。
