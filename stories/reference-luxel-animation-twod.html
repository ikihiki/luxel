RetainedCanvasAnimationTarget

class — RetainedCanvas の UiNode への IAnimationTarget アダプタ。 文字列 path 形式: "{nodeName}/{property}"。サポートする property: transform (Affine2D) translation (Vector2) / translationX/translationY (float) scale (Vector2) / scaleX/scaleY (float) rotation (float radians; 既存の translation/scale を保ったまま回転を再合成) color (uint RGBA) opacity (float) 各 setter は UiNode の既存 dirty 伝播 (transform slot / style slot のみ書込み) を起動するため、 segment データは触らず**部分更新**で済む。
