AnimationController

class — Animation 制御の reactive state ヘルパ (PlaybackState を参照)。 注: 具体的な Widget 構築 (Button/Slider/Segmented) は Sample 側で組む。 本クラスは state の生成と再生 tick の制御を提供するのみで、UI ライブラリへの依存を最小化。 var state = new PlaybackState(); state.Duration.Value = animation.Duration; // Sample 側で Widget 構築: host.SetRoot(VStack[ Button(_ => state.IsPlaying.Value = !state.IsPlaying.Value, "Play/Pause"), Kit.Slider(state.CurrentTime, 0, state.Duration.Value), // ... ]); // 毎フレーム: state.Tick(deltaTime);

メソッド

名前型説明
CreateState() → PlaybackState

BoneEditor

class — 形式非依存の Bone TRS 編集 state + Apply ヘルパ。 Signal で TRS を保持し、Apply で ECS の LocalTransform に反映。 Widget 構築は Sample 側で行う (Kit.Select / Kit.Slider / Button をシグナルに bind)。

class — AnimationController から制御される再生状態 (Signal ベース、reactive)。 1 つの AssetAnimation 単位、または複数 clip を切替えても再利用可能。
