Controls/AssetBrowser/Overview

AssetBrowser

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

アセット/ファイルツリー (ADR-0014): IFileStorage の一覧を TreeView で 表示し、ファイルのクリックを OnOpen (path) で返す — シェルはそれを IDocumentStore.Open へ配線する。フォルダはグループ見出し (クリックで開閉)、 ファイル追加/削除の反映は Refresh。絞り込みは (部分一致)。

イベント

名前型説明
OnOpenUiEvent<AssetBrowser, string>ファイルクリック (第一引数 = 発火元, path)。

パラメータ

名前型説明

Filterstring絞り込みクエリ (TreeView へ透過)。
