AnimationUiBridge

class — AnimationPlayer を UiHost のフレームに結線する拡張。 Animation 側は絶対時刻 (IClock) で駆動、UI 側は dt 累積で Tick するため、ここで橋渡し。

メソッド

名前型説明
Drive(AnimationPlayer player, UiHost host, IClock clock, float dt) → voidAnimationPlayer を IClock で更新し、UiHost を dt で進める標準ヘルパ。 ユーザーは FixedFrameClock や WallClock を渡してフレームの絶対時刻を制御する。

SignalAnimationTarget

class — Luxel.UI の Signal`1 をターゲットにする補助。 AnimationPlayer.Play(animatable, target.For(signal)) で Signal を直接アニメート可能。 Animation core は Luxel.UI を知らず、本 Adapter で疎結合に接続する。

メソッド

名前型説明
For(Signal<T> signal) → Action<T>Signal を Action&lt;T&gt; setter として受け取るヘルパ。AnimationPlayer.Play の第 2 引数に渡す。

SignalTransition

class — Transition を Signal`1 と結ぶ糖衣。Signal 値の変化を ReactiveEffect で 購読し、自動的に補間 setter (animatedSetter) を呼び出す。 使い方: var hovered = new Signal&lt;bool&gt;(false); var animatedColor = Transition.Animate&lt;uint&gt;(v =&gt; node.Color = v, player, clock, 0.3f); using var sub = SignalTransition.Watch(hovered, h =&gt; animatedColor(h ? Red : Blue)); // hovered.Value = true を呼ぶと、color が自動的に補間される

メソッド

名前型説明
Watch(Signal<T> source, Action<T> animatedSetter) → IDisposableSignal の値変化を に流す ReactiveEffect を起こす。 返り値の IDisposable を Dispose すると購読停止 (進行中 transition は AnimationPlayer 側で自然に終了)。
Watch(Func<T> compute, Action<T> animatedSetter) → IDisposablecomputed/関数式の値変化を購読する変種 (毎回 lambda の結果を取り、変化なら setter を呼ぶ)。

TransitionSet

class — 状態切替時のプロパティ別 Transition 仕様を束ねる record。 StateStyle と並行構造で、対応プロパティが値変化したら自動補間する。 tuple 暗黙変換 (TransitionSpec) を使って: transitions: new TransitionSet { Background = (0.3f, CubicBezierCurve.EaseInOut), Scale = (0.1f, CubicBezierCurve.EaseOut), Opacity = 0.2f, // float 一個 → duration のみ }
