FileScriptSource

class — 実ファイルのスクリプト源。FileSystemWatcher で変更を監視し Changed を発火する。 保存直後はエディタがロック/連続イベントを出すので、読み込みは共有 + リトライ付き。連続イベントの畳み込み (デバウンス) は消費側のフレーム先頭 Reload に委ねる。

IScriptSource

ScriptHost

class — C# スクリプト (.csx 意味論 — 最後の式が戻り値、globals のメンバーが裸で見える) のホスト。 Roslyn Scripting の薄いラッパで、エンジンへの参照/using はホストアプリが注入する: var host = new ScriptHost( references: [typeof(Widget).Assembly, typeof(Kit).Assembly], usings: ["System", "Luxel.UI", "Luxel.Controls.Kit"], // 静的クラスも書ける globalsType: typeof(MyGlobals)); ScriptResult r = host.Run("Button(_ => Log(\"hi\"), \"OK\")", myGlobals); コンパイルは**ソース文字列キー**でキャッシュ — 同一ソースの再 Run は再コンパイルしない デバッグ情報付き emit — 実行時例外からスクリプト行番号を取り出せる 決定性の規約: スクリプト内で wall-clock/乱数/await を使わない (snap/E2E と同じ) 既知の制限 (v1): 編集ごとのアセンブリはプロセス終了まで残る (開発時ツールの割り切り — アンロードが要件になったら collectible ALC 化)

コンストラクタ

名前型説明
ScriptHost(IEnumerable<Assembly> references, IEnumerable<string> usings, Type globalsType, string filePath)

メソッド

名前型説明
Check(string code) → IReadOnlyList<ScriptDiagnostic>コンパイル診断のみ (エディタのインライン表示用 — 実行しない)。
Run(string code, object globals) → ScriptResultコンパイル (キャッシュ) して実行する。globals は ctor の globalsType のインスタンス。
OpenSession(object globals) → ScriptSession継続 REPL セッションを開く (DevTools コンソール相当)。1 行目で宣言した変数が 2 行目以降で見える — String) を続けて呼ぶ。

プロパティ

名前型説明

CachedScriptsint (get)キャッシュ済みスクリプト数 (テスト/診断用)。

ScriptHostRegistry

ScriptSession

class — 継続 REPL セッション (Roslyn の ContinueWith) — 前の Submit で宣言した変数/using が 次の Submit で見える。DevTools コンソールや実行中アプリへの 1 行投入に使う。 スレッド非安全 (UI スレッド専有)。

メソッド

名前型説明
Submit(string code) → ScriptResult1 行/1 文を評価し、状態を積む。コンパイル/実行の失敗は ScriptResult に載る (セッションは失敗しても壊れない — 次の Submit は最後に成功した状態から続く)。

プロパティ

名前型説明
LastValueobject (get)直近 Submit の戻り値 (最後の式)。

ScriptWorkspace
