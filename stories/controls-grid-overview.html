Controls/Grid/Overview

Grid

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

行列グリッド。列/行は Fixed(px)/Auto(内容)/Star(比率)。子は .GridColumn(n) 等の fluent 添付プロパティでセルを指定。Flutter 風単一パス (auto 列のみ局所的に intrinsic を測る)。

パラメータ

名前型説明
ColumnsGridLength[]列定義 (Fixed/Auto/Star)。未設定・空 → Star(1) の 1 列。
RowsGridLength[]行定義 (Fixed/Auto/Star)。未設定・空 → Star(1) の 1 行。
