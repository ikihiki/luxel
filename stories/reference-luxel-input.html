InputStack

class — InputContext のスタック。InputBus) 時に上位から順に action を解決し、 上位 context の action が使ったキーは下位に伝わらない (default consume)。 Suspended が true の context は Update されない (UI focus 中の gameplay context を suspend する等)。

コンストラクタ

名前型説明
InputStack()

メソッド

名前型説明
Push(InputContext ctx) → voidcontext を上位に積む (最後に Push したものが最優先)。
Pop() → InputContext最上位を取り除く。
SetSuspended(InputContext ctx, bool suspended) → void指定 context を suspend する (Update から除外)。UI focus 検出などで使用。
Update(InputBus bus) → voidbus に溜まった event を反映し、全 context の action を更新する。 上位 layer から順に action の使用キーを "consume" し、下位には残りだけを渡す。

InputStateMachine

class — state (enum) と InputContext のマッピング。Signal`1 の変化を per-tick で拾い、必要なら stack の top を切り替える (INPUT-M5)。 enum AppState { Menu, Gameplay } var sm = new InputStateMachine&lt;AppState&gt;(stack, AppState.Gameplay); sm.Register(AppState.Menu, menuCtx); sm.Register(AppState.Gameplay, gameplayCtx); // per-frame: sm.State.Value = AppState.Menu; // どこからでも set sm.Sync(); // stack を切り替え state を切り替えると、旧 context は stack から Pop され新 context が Push される (常に top を占有)。 追加の永続 context (常時走る global) を持つ場合は本 SM の外で Push する。

コンストラクタ

名前型説明
InputStateMachine(InputStack stack, TState initial)

メソッド

名前型説明
Register(TState state, InputContext ctx) → InputStateMachine<TState>指定 state のときに使う context を登録。
Activate() → void初回 Sync 前に active な状態の context を stack に push (setup 完了時に呼ぶ)。
Sync() → voidper-tick 呼び出し ─ State が変化していたら stack を切り替える。

プロパティ

名前型説明
