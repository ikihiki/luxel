DiagramLayout

class — 階層 (ランク) 自動レイアウト v1: エッジの最長パスでランクを決め、主軸方向にランクを並べ、 ランク内は出現順に積む (交差最小化はしない — 込み入った図は書き手が宣言順で調整する)。 循環は安全 (逆向きエッジはランク付けに使わず、線だけ引く)。純ロジック — 文字計測は関数で注入。

メソッド

名前型説明
Arrange(DiagramSpec spec, Func<string, (float W, float H)> measure) → DiagramLayoutResultspec を配置して全体サイズと座標を返す。 はラベル 1 行の (幅, 高さ)。

MermaidParser

class — mermaid flowchart の**サブセット**パーサ。対応: 先頭行 flowchart|graph LR|RL|TB|TD|BT、 ノード id[ラベル] / id(ラベル) / id{ラベル} (裸 id はラベル = id の矩形)、 エッジ A --> B / A -->|ラベル| B、コメント %%。 対応外の行は無視する (subgraph/style/click 等 — 全記法は追わない)。

メソッド

名前型説明
Parse(string src) → DiagramSpecmermaid ソースをパースする。対応外の行は無視するので例外は投げない。
