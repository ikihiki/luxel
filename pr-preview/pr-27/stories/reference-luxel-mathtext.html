MathLayoutEngine

class — 数式のボックスレイアウト (TeX の簡易版)。計測と描画プリミティブは**関数注入** — 純ロジックとしてテストでき、widget 側が VectorFont/Scene2D の closure を渡す。 script は 0.7 倍、分数線・根号・括弧はストローク描画 (グリフに依存しない)。

TexParser

class — TeX **サブセット**パーサ。対応: ^ _ {}、\frac \sqrt \vec、 \begin{matrix/pmatrix/bmatrix} (&amp; / \\)、ギリシャ文字・演算子コマンド (置換表は TexText と同じ)、関数名 (\sin 等 = 立体)。 未知のコマンドは \cmd のまま立体で出す (豆腐にしない)。

メソッド

名前型説明
Parse(string tex) → MathNodeTeX 文字列をパースして数式ノードを返す (要素 1 つなら MathRow に包まない)。

TexText

class — インライン数式 ($...$) の TeX サブセット → Unicode 正規化。 ギリシャ文字・演算子コマンドの置換と、単一トークンの ^/_ を上付き/下付き文字へ。 **パース時に一度だけ正規化して文書へ焼き込む** (emoji/SmartyPants と同じ方針 — 表示・検索・シリアライズのオフセットが常に一致し、round-trip は 1 回で収束する)。 変換できないコマンドはそのまま残す (豆腐にしない)。本格レイアウト (分数/行列) は ブロック数式 $$...$$ = Luxel.MathText 側の担当。

メソッド

名前型説明
ToUnicode(string tex) → stringTeX サブセットを Unicode へ正規化する。
