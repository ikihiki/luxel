SurfaceView

iframe 相当の埋め込みサーフェス。子 RetainedCanvas + 子 UiHost + 専用 framebuffer を所有し、 親キャンバス上では image ノード 1 つ (Kind=2, bindless バッファサンプリング) として描かれる。 - 子は透過 (premultiplied) で描かれ、変更があったフレームだけ GPU 内で再ラスタライズされる (CPU 読み戻しなし) - 入力はローカル座標のまま子 UiHost へ転送 (pointer/drag/wheel、フォーカス時は key/文字/IME) - Single}) で子ルートを差し替え — 親ツリーの再構築は不要 (ギャラリーのプレビュー切替用) - フォーカス/オーバーレイ/状態は子側に閉じる。子の Dialog 等はこの矩形内にクリップされる 制限: 親の Tab/Escape は親 UiHost が先に消費するため子へ届かない (v1)。破棄は所有者が Dispose。
