Icon

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

ベクターアイコン (24x24 ビューボックスのパスを size に拡大)。色はテーマ束縛可。

イベント

名前型説明
OnClickUiEvent<Icon>クリック (任意)。ハンドラがあるときだけヒット登録する — ツリーのシェブロン等、 アイコン単体をボタンにしたい場面用 (Hand カーソル、当たりは少し広め)。

パラメータ

名前型説明
KindIconKindアイコン種別。
IconSizefloat表示サイズ (px、正方形)。基底 Size と衝突するため iconSize。
Strokefloat線の太さ (px)。
Coloruint色。未設定 → テーマ Text。
