Controls/MenuBar/Overview

MenuBar

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

メニューバー (ADR-0013): CommandRegistry のメニュー階層を横一列のルートに描き、 クリックでドロップダウン (項目 = タイトル + キーバインド、disabled はグレー、深い階層は グループ見出しでインライン展開)。アクティブ doc の寄与は (Build 中に評価 — 中で signal を読めば追従) で合成。
