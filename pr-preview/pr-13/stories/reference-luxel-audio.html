AudioBus

class — ミキサーの階層ノード。Master / Music / SFX / Voice のような 音量グループ。 親 bus を持つと、実効音量は自身 × 親のチェーンで計算される。UI の master slider を Signal で bind すれば 全 sound source に同時に効く。 XAudio2 の SubmixVoice を使わず、AudioSource / AudioSource3D が Tick 時に EffectiveVolume を掛け算するシンプル実装。

AudioClip

class — メモリ上のデコード済み PCM 音声。Format に従って PcmData を解釈する。 Resources 経由でロード (resources.Load&lt;AudioClip&gt;("bgm.ogg")) or 直接 new で生成する。 SFX は通常この形式 (全展開)、BGM は AUDIO-M7 で streaming source を別途用意する。

AudioSource3D

class — 3D 空間に配置される音源。Position を持ち、per-frame AudioListener) で AudioListener との距離を計算して volume + pan を voice に流す。 距離減衰は linear: distance ≤ MinDistance で 100%、≥ MaxDistance で 0%、間は線形。 pan は listener の Right ベクトルとの内積 (-1 = 完全左、+1 = 完全右)。 (Doppler shift は M7+ で追加検討。)

StreamingVoice

class — IAudioStream を**デコードしながら再生**する声 — BGM 等の長尺用。 と 同じ「毎 Tick Pump + キュー深さ &lt; QueueDepth まで補充」方式なので専用スレッド不要 (フレームレート依存のジッタはキュー深さで吸収)。チャンクは float→16bit へ量子化して submit。 ループは LoopingStream でラップして渡す (このクラスは終端で止まる)。 駆動: フレームループ/AddAnimation から毎 Tick Pump を呼ぶ。

コンストラクタ

名前型説明
StreamingVoice(IAudioBackend backend, IAudioStream stream, float chunkSeconds, int queueDepth)

メソッド

名前型説明
Pump() → void毎 Tick 呼ぶ: キューが QueueDepth 未満なら、終端までチャンクをデコードして submit する。
Stop() → void再生を止めてキューを捨てる (Pump を止めれば以後補充されない)。
Restart() → void先頭から再生し直す。
Dispose() → void

プロパティ

名前型説明
QueueDepthint (get)先読みするチャンク数 (この数までキューを満たす)。
IsPlayingbool (get)再生中 (開始済み・未 Dispose)。
Finishedbool (get)ストリーム終端に達し、キューも空になった (再生完了)。
BuffersQueuedint (get)キューに残っているバッファ数。

WavStream

class — WAV (RIFF PCM) を**逐次**デコードする IAudioStream — 依存なしの自前パーサ。 16-bit 整数 PCM (fmt タグ 1) と 32-bit float (fmt タグ 3) に対応。ヘッダは構築時に読み、 data チャンクは Single}) で必要な分だけ下層 Stream から読み込む (全展開しない)。 Reset は data 先頭へ seek する (下層はシーク可能であること — FileStream 等)。
