Controls/ColorPicker/Overview

ColorPicker

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

カラーピッカー。スウォッチ + hex 表示のトリガーをクリックすると、 パレット + R/G/B スライダー + hex 入力 (正規表現規制) のオーバーレイが開く。 値は RGBA の Signal`1 束縛 — どの経路の編集も即時に部分更新で反映される。

パラメータ

名前型説明
ColorSignal<uint>RGBA 色の signal (パレット/スライダー/hex どの経路の編集も書き戻す)。
