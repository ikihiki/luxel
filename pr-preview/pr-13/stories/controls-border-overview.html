Controls/Border/Overview

Border

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

背景色 + padding + (任意で) クリップを持つ単一子コンテナ。 スタイルはすべて [UiParam] な Bindable`1 フィールド。状態別の上書きは 生成された .When(WidgetState.Hover, background: ...) が Widget) で積み、 fluent .Transition(...) を宣言すると状態変化で自動補間される。
