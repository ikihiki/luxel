OrbitCamera

struct — 3D 軌道カメラ (ターゲットを中心に yaw/pitch/distance で周回)。KnockdownStory のドラッグ軌道カメラを部品化。 純 Numerics 数学で ViewProjection を計算する (GPU 非依存・テスト可能)。 3D の follow/shake は v1 スコープ外 — これは viewProj 算出とドラッグ操作 (Single)/Single)) のみ。

コンストラクタ

名前型説明
OrbitCamera(Vector3 target, float yaw, float pitch, float distance, float fovYRadians, float aspect, float near, float far)

メソッド

名前型説明
Orbit(float deltaYaw, float deltaPitch, float pitchLimit) → voidドラッグで周回する。pitch は真上/真下 (ジンバルロック) の手前で ± にクランプ。
Dolly(float factor, float min, float max) → void距離をズーム (係数を掛けて .. にクランプ)。

プロパティ

名前型説明
EyeVector3 (get)視点 (カメラ位置)。yaw/pitch/distance から算出。
ViewMatrix4x4 (get)ビュー行列 (右手系、上方向 +Y)。
ProjectionMatrix4x4 (get)透視投影行列。
ViewProjectionMatrix4x4 (get)view × proj。シェーダの root args にはこれ (必要なら転置) を渡す。

WindowSystem

class — ウィンドウシステムの公開窓口 (グラフィックデバイスに対するウィンドウ側の窓口)。 バックエンド (Win32 等) を包み、ウィンドウの生成・一覧・メッセージポンプを提供する。 using var windows = new WindowSystem(Win32WindowBackend.Create()); NativeWindow main = windows.CreateWindow(new WindowDesc("App", 800, 600)); var swapchain = device.CreateSurface(main.Handle, (uint)main.Width, (uint)main.Height); while (windows.Pump()) { ...描画して swapchain.Present... }

コンストラクタ

名前型説明
WindowSystem(IWindowBackend backend)

メソッド

名前型説明
CreateWindow(WindowDesc desc) → NativeWindowウィンドウを生成する。メッセージポンプと同じスレッドから呼ぶこと。
Pump() → bool保留メッセージを処理し、閉じたウィンドウを一覧から外す。生存ウィンドウが残っていれば true。
Dispose() → void

プロパティ

名前型説明
Namestring (get)
WindowsIReadOnlyList<NativeWindow> (get)生存ウィンドウのスナップショット (閉じたものは Pump で除去済み)。
