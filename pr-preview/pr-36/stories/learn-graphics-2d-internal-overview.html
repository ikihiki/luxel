2D rasterizer pipeline

Warning

ここで扱うlayout、tile size、shader stageは内部実装です。通常の2D描画コードはIRasterizer2DとScene2Dを使います。

難易度: Advanced　 実行環境: Gallery / Standalone　 Backend: GPU compute　 前提知識: 2D描画

前へ: IncrementalUpdates　 次: Flattening

Pipeline上の位置

Scene2D / RetainedCanvas → flattened geometry → SoA encoding → bounds → tile bins → fine coverage + composite → RGBA target

このstage: 全stageの接続

入力と出力

  • 入力: Scene2DまたはRetainedCanvas
  • 出力: RGBA render target

Core invariant

C#側のbuffer rangeとdispatch順序が、shader側の読み取りlayoutと一致する。

Correctnessと失敗時の確認

描画が欠ける場合は入力path、encoded range、bounds、tile membership、coverage、compositeの順に切り分けます。
