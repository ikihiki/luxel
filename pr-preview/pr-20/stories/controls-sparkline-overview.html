Controls/Sparkline/Overview

Sparkline

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

数値系列の小型グラフ (折れ線 or 棒)。値は Single}) で**実体化後も差し替え可能** — グラフノードの Content だけ差し替えて Invalidate する (ListView と同じ流儀。fps/メモリ等の履歴向け)。 SetValues 毎に Effect は作らない — 色は Realize 時の単一 Effect が流す (ノード色がシーン色を上書きする 網膜モードの性質を利用し、シーンは白で描く)。
