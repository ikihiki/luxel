Controls/DocumentTabs/Overview

DocumentTabs

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

複数ドキュメントのタブ帯 (ADR-0014)。ダーティ ●・× 閉じ・D&amp;D 並べ替え・オーバーフロー (幅超過はタブを等比縮小 + ラベルクリップ) を持つ。既存 Tabs はビュー切替専用 — こちらはドキュメント一覧をデータで受け、開閉/並べ替えはイベントで呼び出し側 (シェル) に返す。 同じ を持つ帯どうしはタブをドラッグで移せる (DockHost のグループ間移動)。

イベント

名前型説明
OnActivateUiEvent<DocumentTabs, string>タブクリック (id)。
OnCloseUiEvent<DocumentTabs, string>× クリック (id)。閉じるかはシェルが決める (ダーティ確認など)。
OnDropTabUiEvent<DocumentTabs, string, int>タブがこの帯へドロップされた (id, 挿入 index — 除去前の並び基準)。 同一帯の並べ替えと他帯からの移動の両方がここに来る。

パラメータ

名前型説明
ItemsIReadOnlyList<DocTab>タブ一覧 (表示順)。
Activestringアクティブタブの id (null = なし)。
DragChannelobjectD&amp;D の受け入れ範囲 — 同じ channel オブジェクトを持つ帯間でタブを移せる (null = この帯内の並べ替えのみ)。
