Controls/TableBlock/Overview

TableBlock

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

テーブル埋め込みブロックの標準 widget (GFM pipe table)。グリッド描画 (罫線 + ヘッダ地色 + 列整列) と **セルの in-place 編集**: クリックでセル選択 + 編集開始、Tab/Shift+Tab/Enter/↑↓ でセル移動、 最下段で Enter → 行追加、空行の先頭で Backspace → 行削除、Esc で取消。 編集はローカルコピー上で行い、**フォーカスを失ったとき 1 op として Commit** (ReplacePayload = undo 可) — セル間移動のたびに undo が刻まれない。ITextInput 実装 (編集中セル = TSF 文書) で日本語入力可。 登録: widgets.Register("table", TableBlocks.Factory())。
