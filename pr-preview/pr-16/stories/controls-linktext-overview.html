Controls/LinkText/Overview

LinkText

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

リンク風のクリック可能テキスト (背景・余白なし、左寄せ)。ナビゲーション項目 (サイドバー/ツリー/パンくず) 向け — ボタンの中央寄せ+padding が要らない場面で使う。 通常は控えめな色、hover で本文色へフェード、 でアクセント色 (選択中表示)。

イベント

名前型説明
OnClickUiEvent<LinkText>クリック (EV: 第一引数は発火元の LinkText 自身)。

パラメータ

名前型説明
Textstring
FontSizefloat文字サイズ。未設定 → テーマ FontSm。
Activebool選択中/現在地の強調 (色がアクセントになる)。
Coloruint (状態対応)通常色。未設定 → Active ? Primary : TextMuted。
HoverColoruint (状態対応)hover 色。未設定 → Active ? Primary : Text。
