Controls/Slider/Overview

Slider

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

スライダー。値=signal。クリック/ドラッグで設定、←→ で微調整。フィル/つまみは transform 部分更新。 trackColor/fillColor/knobColor は [UiParam] Bindable、状態別は On(WidgetState.Focused, ...)、 SliderSlot.Knob(() => widget) で内部 primitives を slot 上書き可。
