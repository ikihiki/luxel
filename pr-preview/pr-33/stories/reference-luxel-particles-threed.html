ParticleBillboards

class — ParticleSystem をカメラ向きビルボード (インスタンス quad) で 3D 描画する。生存パーティクルを RenderBuffer`1 の instance 配列に詰め、billboard.slang が SV_InstanceID から 各パーティクルを 6 頂点の quad にカメラの right/up 軸で展開する。深度テストあり・書き込み無し + アルファブレンド。 描画順は発生順 (ソートしない — 半透明の割り切りを Docs に明記)。
