SoA scene encoding

  • Pipeline上の位置
  • 入力と出力
  • Core invariant
  • Correctnessと失敗時の確認

Warning

ここで扱うlayout、tile size、shader stageは内部実装です。通常の2D描画コードはIRasterizer2DとScene2Dを使います。

難易度: Advanced　 実行環境: Gallery / Standalone　 Backend: GPU compute　 前提知識: 2D描画

前へ: Flattening　 次: Abi

Pipeline上の位置

Scene2D / RetainedCanvas → flattened geometry → SoA encoding → bounds → tile bins → fine coverage + composite → RGBA target

このstage: segments → SoA buffers

入力と出力

  • 入力: flattened segments、shape/style/transform/clip/order
  • 出力: GPU buffer rangeとroot arguments

Core invariant

各shapeのrangeがsegment列を正確に指し、order bufferがpainter orderを保存する。

Correctnessと失敗時の確認

rangeのoff-by-one、空shape、transform/style slotのずれをdiagnosticで確認します。
