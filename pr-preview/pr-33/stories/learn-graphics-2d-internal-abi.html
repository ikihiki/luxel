  • Pipeline上の位置
  • 入力と出力

Warning

ここで扱うlayout、tile size、shader stageは内部実装です。通常の2D描画コードはIRasterizer2DとScene2Dを使います。

難易度: Advanced　 実行環境: Gallery / Standalone　 Backend: GPU compute　 前提知識: 2D描画

前へ: SceneEncoding　 次: Bounds

Pipeline上の位置

Scene2D / RetainedCanvas → flattened geometry → SoA encoding → bounds → tile bins → fine coverage + composite → RGBA target

このstage: host layout ↔ shader layout

入力と出力

  • 入力: GpuSegment/GpuPath/GpuTransform/GpuStyle/GpuClip
  • 出力: shaderから同じ意味で読めるbytes

Core invariant

field order、size、alignment、bindless indexがC#とSlangで一致する。

Correctnessと失敗時の確認

ABI test、shader cacheのinputs hash、root argument sizeを確認します。layout変更は片側だけで完結しません。
