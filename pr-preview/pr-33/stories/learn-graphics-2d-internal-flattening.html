Curve flattening

  • 入力と出力

Warning

ここで扱うlayout、tile size、shader stageは内部実装です。通常の2D描画コードはIRasterizer2DとScene2Dを使います。

難易度: Advanced　 実行環境: Gallery / Standalone　 Backend: GPU compute　 前提知識: 2D描画

前へ: Overview　 次: SceneEncoding

Pipeline上の位置

Scene2D / RetainedCanvas → flattened geometry → SoA encoding → bounds → tile bins → fine coverage + composite → RGBA target

このstage: curve → line segment

入力と出力

  • 入力: quadratic/cubic Bézierとworld-unit tolerance
  • 出力: ordered line segment列

Core invariant

各subdivisionは許容誤差以内で元curveを近似し、contour orderを保存する。

Correctnessと失敗時の確認

toleranceが小さすぎるとsegment数が増え、大きすぎると輪郭が崩れます。open/closed contourと2点未満の破棄も確認します。
