Controls/Accordion/Overview

Accordion

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

折りたたみ。ヘッダクリックで展開トグル。コンテンツはクリップ高さをアニメ (reveal)。 注: 単一パスのため周囲の再レイアウトはしない (末尾配置向け)。Size はヘッダ高のみ。
