DevStats

class — ゲームが 1 行で観測に載せる汎用 key-value watch。score / 残弾 / HP / 状態機械の現在状態や パーティクル Alive 数など、printf デバッグの受け皿。値は String) で いつでも上書きし、フレームループが Flush で 30f 毎にまとめて Custom へ emit する。 ゼロコスト規律: DevTools が繋がっていない (購読者ゼロ) ときは String) は String) の bool 判定だけで即 return し、辞書書き込みも割り当ても行わない。

メソッド

名前型説明
Set(string key, string value) → void文字列値を観測に載せる (購読者が居なければ何もしない)。
Set(string key, double value) → void数値を観測に載せる (小数 3 桁、invariant)。
Set(string key, long value) → void整数を観測に載せる。
Set(string key, int value) → void整数を観測に載せる。
Set(string key, bool value) → void真偽値を観測に載せる。
Snapshot() → DiagStat[]現在の全 key-value を key 昇順で取得する (テスト/emit 用の決定的スナップショット)。
Flush() → void溜まった key-value を Custom へ emit する (フレームループが 30f 毎に呼ぶ)。
Clear() → void全 key を消す (シーン切替時など。テストの分離にも使う)。
