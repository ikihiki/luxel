Controls/Select/Overview

Select

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

単一選択ドロップダウン。選択ラベルを表示し、クリックで候補メニューを開く (オーバーレイ)。

パラメータ

名前型説明
Optionsstring[]候補ラベル一覧。
SelectedSignal<int>選択 index の signal (選択で書き戻す)。
FontSizefloat文字サイズ。未設定 → テーマ Font - 1。
Backgrounduint背景色。未設定 → テーマ SurfaceAlt。
