Controls/CheckBox/Overview

Check

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

テーマ駆動のチェックボックス。チェック状態は signal 束縛、トグルは色/チェック印の部分更新。 スタイルは [UiParam] な Bindable`1 フィールド。Tailwind の checked: は On(WidgetState.Checked, Bg(Tw.Blue500)) — WidgetState) が checked signal を読む。 未設定はテーマ (checked ? Primary : SurfaceAlt) にフォールバック。
