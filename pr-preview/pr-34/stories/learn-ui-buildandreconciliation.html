Build, layout, and reconciliation

Buildはlazyで、最初のLayout時に呼ばれます。signal変更は同期的にRootをnullへし、次のLayoutで最新値を使って一度だけ再Buildします。このheadless sampleはBuild reconciliationまでを検証します。UiHost、input hit testing、RetainedCanvasへの部分Realizeはwindow/GPU host側の責務であり、このbundleには含まれません。
