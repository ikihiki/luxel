Controls/NavigationView/Overview

NavigationView

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

A fixed navigation pane and a single content child. Use NavigationView(navigation, items)[content] like other layout controls.

パラメータ

名前型説明
NavigationNavigationNavigation state shared with the content.
ItemsIReadOnlyList<NavigationViewItem>Destinations displayed in the pane.
ShowBackButtonboolWhether the stable back-button row is displayed.
PaneWidthfloatWidth of the expanded navigation pane.
ItemHeightfloatHeight of each navigation row.
PaneBackgrounduint (状態対応)Pane background. Unset uses the current theme surface.
ItemForegrounduint (状態対応)Normal item foreground. Unset uses muted theme text.
SelectedBackgrounduint (状態対応)Selected item background. Unset uses the alternate theme surface.
SelectedForegrounduint (状態対応)Selected item foreground. Unset uses the theme primary color.
