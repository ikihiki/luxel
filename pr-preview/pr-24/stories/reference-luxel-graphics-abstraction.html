IGpuBackend

interface — バックエンド (Vulkan / D3D12) が実装する低レベル抽象。 公開 API (GpuDevice 等) はこのインターフェイスのみに依存し、 各バックエンドの具象型 (Silk.NET / Vortice) はバックエンドプロジェクト内に隔離する。

メソッド

名前型説明
CreateBuffer(ulong size, GpuMemoryKind kind) → IGpuBackendBuffergpuMalloc。指定種別のメモリからバッファをサブアロケートする。
CreateComputePipeline(ReadOnlySpan<byte> shaderBlob, string entryPoint) → IGpuBackendPipelinecompute パイプラインを生成する。
CreateGraphicsPipeline(ReadOnlySpan<byte> vsBlob, string vsEntry, ReadOnlySpan<byte> psBlob, string psEntry, GpuRasterDesc raster) → IGpuBackendPipelinegraphics パイプラインを生成する (頂点 + ピクセル)。Vulkan は同一 blob を vs/ps に使える。
CreateRenderTarget(uint width, uint height, GpuFormat format) → IGpuBackendTextureレンダーターゲット (カラー) テクスチャを生成する。
CreateDepthTarget(uint width, uint height, GpuFormat format) → IGpuBackendTexture深度ターゲットを生成する。
CreateSampledTexture(uint width, uint height, GpuFormat format, ReadOnlySpan<byte> data) → IGpuBackendTextureサンプリング可能なテクスチャを生成し、ピクセルデータをアップロードする。
CreateSampler(GpuSamplerFilter filter, GpuSamplerAddress address) → IGpuBackendSamplerサンプラを生成する。
CreateSurface(NativeSurfaceDescriptor descriptor, uint width, uint height) → IGpuBackendSurfaceネイティブウィンドウへのスワップチェーン提示面を生成する。

プロパティ

名前型説明
Namestring (get)バックエンドとデバイスの人間可読な名前 (例: "Vulkan / NVIDIA RTX ...")。
KindGpuBackendKind (get)このバックエンドの種別。シェーダの形式選択 (SPIR-V / DXIL) に使う。
MainQueueIGpuBackendQueue (get)主キュー (汎用 graphics+compute+copy)。

IGpuBackendBuffer

interface — バックエンドのバッファハンドル。ブログの「64bit ポインタ」と CPU マップを表す。

プロパティ

名前型説明
Sizeulong (get)バイト数。
DeviceAddressulong (get)シェーダから参照できる 64bit GPU アドレス (BDA / GPUVA)。
BindlessIndexuint (get)bindless ヒープ内のインデックス。D3D12 では ResourceDescriptorHeap[index] 用。 Vulkan の bindless 対応は M6 で導入予定 (現状は未使用)。
MappedPointervoid* (get)CPU からマップされた先頭ポインタ。マップ不可なら null。

IGpuBackendCommandBuffer

interface — バックエンドのコマンドバッファ。記録 API を提供する。

メソッド

名前型説明
SetComputePipeline(IGpuBackendPipeline pipeline) → voidcompute パイプラインをバインドする。
SetRootConstants(ReadOnlySpan<byte> data) → voidルート引数 (小さな定数バイト列) を設定する。Vulkan は push 定数、D3D12 は root 32bit 定数へ書く。
Dispatch(uint groupCountX, uint groupCountY, uint groupCountZ) → voidcompute ディスパッチ。
SetGraphicsPipeline(IGpuBackendPipeline pipeline) → voidgraphics パイプラインをバインドする。
BeginRendering(IGpuBackendTexture color, IGpuBackendTexture depth, float r, float g, float b, float a, float clearDepth) → voidカラー(+任意で深度)ターゲットへの dynamic rendering を開始し、クリアする。
EndRendering() → voiddynamic rendering を終了する。
Draw(uint vertexCount, uint instanceCount) → void描画 (頂点プル)。
CopyTextureToBuffer(IGpuBackendTexture source, IGpuBackendBuffer destination, uint rowLengthPixels) → voidテクスチャ全体をバッファへコピーする (読み戻し用)。rowLengthPixels=0 は密な行。
CopyBufferToBuffer(IGpuBackendBuffer source, IGpuBackendBuffer destination, ulong bytes) → voidバッファ間コピー (先頭から bytes 分)。WC メモリの読み戻しを避けて HostCached (READBACK) バッファへ落とす用途など。
Barrier(GpuStage source, GpuStage destination, GpuHazard hazard) → voidステージベースのバリアを発行する。
Finish() → void記録を終了する (投入可能な状態にする)。

メソッド

IGpuBackendSurface

interface — スワップチェーン提示面。RGBA8 バッファをバックバッファへコピーして present する。

メソッド

名前型説明
Present(IGpuBackendBuffer source, uint srcStridePixels, uint width, uint height) → voidRGBA8 バッファの (0,0)-(width,height) をバックバッファへコピーして present する。 はソースの 1 行のピクセル数 (行パディング込み)。
Resize(uint width, uint height) → voidサイズ変更時にスワップチェーンを再生成する。
