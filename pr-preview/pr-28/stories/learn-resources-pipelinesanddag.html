Typed pipelines and dependency DAG

難易度: Intermediate　 実行環境: Standalone / Headless　 Backend: IO / CPU / GPU lanes　 前提知識: Resources overview

前へ: Overview　 次: ReloadAndLifetime

IResourceSourceがURIからbytesを読み、IResourceStep<TIn,TOut>が型を変換します。requested output typeからstepを逆引きするため、byte[] → decoded → GPU resourceの任意長chainを組めます。step内のLoadContext.Loadはdependency edgeを作り、共有・reload伝播・eviction順序へ使われます。

var files = new MemoryFileSystem();
files.Set("hello.txt", Encoding.UTF8.GetBytes("hello resources"));
using var resources = new ResourceSystem(
    sources: [new FileSource(files)],
    steps: [new Utf8TextStep()]);
using ResourceHandle<TextAsset> handle = resources.Load<TextAsset>("hello.txt");
await handle.Ready;
