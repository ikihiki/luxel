Controls/Layout のデモで使う基本レイアウトコントロールです。個別カテゴリを持たないプリミティブをまとめています。

Box

角丸塗りボックス (子なし)。サイズは共通引数 (width/height)、伸縮は hAlign/vAlign: Stretch。

パラメータ

名前型説明
Backgrounduint塗り色。未設定 → テーマ SurfaceAlt。
Roundedfloat角丸半径 (px)。

Stack

子を縦/横に順に並べる単純コンテナ。

パラメータ

名前型説明
Verticalbooltrue=縦に積む (既定)。向きは VStack/HStack sugar もある。
Spacingfloat子要素間の間隔 (px)。

Center

子を中央(または指定整列)に配置するコンテナ。与えられた領域いっぱいに広がる。

Spacer

固定サイズの空き (区切り/余白)。描画なし。サイズは共通引数 (width/height)。
