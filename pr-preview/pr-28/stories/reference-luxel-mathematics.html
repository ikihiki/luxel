Affine2D

struct — 2x3 アフィン変換。screen = (A*x + C*y + E, B*x + D*y + F)。

メソッド

名前型説明
Translate(float x, float y) → Affine2D
Scale(float sx, float sy) → Affine2D
Rotate(float radians) → Affine2D
Mul(Affine2D m1, Affine2D m2) → Affine2D合成: 返り値を点に適用すると m1(m2(p)) と同じ (m2 を先に適用)。world = Mul(parent, local)。
Apply(Vector2 p) → Vector2
TryInvert(Affine2D inv) → bool逆変換を求める (ヒットテストでワールド→ローカルへ写す用)。特異 (det≈0) なら false。

OrbitCamera

struct — ターゲットを中心にyaw/pitch/distanceで周回する3D軌道カメラ。 純粋なNumerics計算でViewProjectionを求め、 Single)とSingle)で姿勢と距離を更新する。

コンストラクタ

名前型説明
OrbitCamera(Vector3 target, float yaw, float pitch, float distance, float fovYRadians, float aspect, float near, float far)

メソッド

名前型説明
Orbit(float deltaYaw, float deltaPitch, float pitchLimit) → voidドラッグで周回する。pitch は真上/真下 (ジンバルロック) の手前で ± にクランプ。
Dolly(float factor, float min, float max) → void距離をズーム (係数を掛けて .. にクランプ)。

プロパティ

名前型説明
EyeVector3 (get)視点 (カメラ位置)。yaw/pitch/distance から算出。
ViewMatrix4x4 (get)ビュー行列 (右手系、上方向 +Y)。
ProjectionMatrix4x4 (get)透視投影行列。
ViewProjectionMatrix4x4 (get)view × proj。シェーダの root args にはこれ (必要なら転置) を渡す。

フィールド

名前型説明
TargetVector3注視点 (ワールド)。
Yawfloat方位角 (ラジアン、Y 軸まわり)。
Pitchfloat仰角 (ラジアン、± で上下)。
Distancefloat注視点からの距離。
FovYRadiansfloat垂直画角 (ラジアン)。
Aspectfloatアスペクト比 (幅/高さ)。
Nearfloatニアクリップ。
Farfloatファークリップ。

コンストラクタ

名前型説明

メソッド

Xorshift64

struct — 割り当てなしで動作する決定的xorshift64疑似乱数生成器。 同じseedから同じ系列を生成し、0 seedは既定seedへ丸める。

コンストラクタ

名前型説明
Xorshift64(ulong seed)

メソッド

名前型説明
NextULong() → ulong次の 64bit。
NextFloat() → float[0,1) の float (上位 53bit)。
NextRange(float min, float max) → float[min,max) の一様乱数。
NextSigned() → float[-1,1) の float。
