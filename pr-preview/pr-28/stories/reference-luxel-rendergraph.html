IRenderExtractor

interface — シーン側 (2D/UI/3D ECS など) を毎フレーム GPU バッファへ抽出する抽象。 レンダーグラフはこの抽象を介してシーンを取り込むことで、UI/ECS/独自シーンを問わず同じ pass builder で パイプラインを組めるようになる (scene-agnostic 設計)。 強制ではない: 既存の GpuBuffer をそのまま String) しても良い。 IRenderExtractor は「シーン更新 → GPU バッファ書込」の操作を一段抽象化する規約であり、 RG-M4 (3D + ECS) では Render3DExtractSystem 等が実装する想定。

メソッド

名前型説明
Extract(ExtractContext ctx) → voidシーンを GPU バッファへ抽出する。レンダーグラフ構築の前段で呼び出されることを想定。 必要な GpuBuffer は extractor 自身が確保 / 保持し、 それを String) でグラフへ取り込む流儀。

PassBuilder

class — パスのリソース依存を宣言する builder。PassContext}) 呼び出しでグラフへ確定登録される。 同じハンドルへの重複 Read/Write は許容する (Compile 相で集約)。

メソッド

名前型説明
Read(BufferHandle handle, ResourceUsage usage) → PassBuilderこのパスが読むバッファを宣言する。
Write(BufferHandle handle, ResourceUsage usage) → PassBuilderこのパスが書くバッファを宣言する。
ReadWrite(BufferHandle handle) → PassBuilder同一パスで読み書き両方する場合 (ReadWrite)。
Read(TextureHandle handle, TextureUsage usage) → PassBuilderこのパスが読むテクスチャを宣言する。
Write(TextureHandle handle, TextureUsage usage) → PassBuilderこのパスが書くテクスチャを宣言する。
Execute(Action<PassContext> body) → voidexecute lambda を確定登録する。パスはここで初めて RenderGraph に追加される。

PassContext

struct — パスの execute lambda に渡される実行コンテキスト。物理 GPU リソースの解決と、 シェーダの root args 用に BindlessIndex を引くショートカットを提供する。

メソッド

名前型説明
Buffer(BufferHandle handle) → GpuBuffer論理ハンドルを物理 GpuBuffer に解決する (Compile 後でのみ有効)。
BindlessIndex(BufferHandle handle) → uint論理ハンドルから BindlessIndex を引く (シェーダの root args に流し込む用)。
Texture(TextureHandle handle) → GpuTexture論理ハンドルを物理 GpuTexture に解決する (Compile 後でのみ有効)。

RenderGraph

class — レンダーグラフ (RG-M1: Setup/Compile/Execute 三相 + バッファ寿命解析 + 自動 stage バリア)。 パスとリソース依存を builder で宣言し、Compile でデッドパスカリング/物理リソース割当/バリア計算を行い、 GpuCommandBuffer) で per-pass コールバックを順に駆動する。 設計上、シーン側 (RetainedCanvas/UI/ECS) は一切知らない。入力は GPU ハンドル (BufferHandle) のみ。

コンストラクタ

名前型説明
RenderGraph(GpuDevice device)

メソッド

名前型説明
ImportBuffer(GpuBuffer buffer, string name) → BufferHandleExternal な既存 GpuBuffer をグラフに取り込む。寿命/解放はユーザー責任。
CreateBuffer(BufferDesc desc, string name) → BufferHandleTransient バッファを宣言する。物理メモリは Compile 相で割り当てる。
ImportTexture(GpuTexture texture, string name) → TextureHandleExternal な既存 GpuTexture をグラフに取り込む。寿命/解放はユーザー責任。
CreateTexture(TextureDesc desc, string name) → TextureHandleTransient テクスチャを宣言する。物理リソースは Compile 相で割り当て、同形なら aliasing。
AddPass(string name, PassQueue queue) → PassBuilder新しいパスを追加する。返り値の builder で Read/Write/Execute を宣言する。
Execute(GpuCommandBuffer cmd) → voidグラフを compile し、即座に execute する。1 フレームで 1 度呼ぶ想定。 内部で寿命解析 → 物理リソース割当 → パス順に execute + 自動バリア挿入を行う。
BuildDiagnostic() → DiagRenderGraph計装用に Compile 後の最終形をスナップショット。テストからも呼べる。
GetPhysicalSlot(TextureHandle handle) → intテスト用: テクスチャの aliasing slot 番号。
IsAliased(TextureHandle handle) → boolテスト用: テクスチャが aliasing で物理共有しているか。
GetPhysicalSlot(BufferHandle handle) → intリソースの同形グループ内 slot 番号 (aliasing 確認用、未割当なら -1)。
IsAliased(BufferHandle handle) → boolリソースが aliasing で物理バッファを他リソースと共有しているか。
IsPassCulled(int passIndex) → boolCompile 相のデッドパスカリングで除外されたか。
Dispose() → void
