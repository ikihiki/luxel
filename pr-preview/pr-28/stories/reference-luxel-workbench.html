DockTree

class — 領域 + タブグループの再帰木 + 窓内フローティング (ADR-0010)。**不変** — 各操作は新しいツリーを 返す (テキスト/ノードスタックと同じ不変状態の流儀)。描画は ADR-0014 の DockHost。 正規化規則: 空グループは消える (ルートは空グループ 1 つで残る)・子 1 つの分割は繰上げ・ 同方向の入れ子分割は親へ畳む (サイズは按分)・空になったフロートは消える。 フロートのグループも Groups/Int32) に含まれ、MoveTab/AddTab の 対象にできる (Dock でフロートグループを指すと分割せず末尾追加)。

RemoveTab(string tab) → DockTreeタブを外す。空になったグループ/フロートは畳む (ルートは空グループで残る)。無ければ no-op。

ResizeFloat(int groupId, float w, float h) → DockTreeフロートをリサイズする (最小 120×80)。無ければ no-op。
WithSizes(int splitId, IReadOnlyList<float> sizes) → DockTree分割の子サイズを差し替える (スプリッタドラッグ)。合計 1 に正規化。 個数不一致は ArgumentException。

IEditorDocument

interface — Workbench に載る 1 ドキュメントの**不透明ハンドル** (ADR-0010)。各エディタスタック (テキスト = Luxel.Document、ノード = Luxel.NodeGraph、…) がこれを実装するアダプタを持ち、 **内部モデル (EditorState/NodeGraphState/…) は統一しない** — シェルは Kind とこの契約 だけを見る。view の実体化は呼び側 (DockHost 等) の責務で、本インターフェースは canvas/GPU に触れない。

Workspace
