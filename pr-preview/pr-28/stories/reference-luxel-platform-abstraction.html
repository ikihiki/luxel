IWindowBackend

interface — ウィンドウシステムのバックエンド (Win32 / 将来の他 OS) が実装する低レベル抽象。 GPU バックエンド抽象と同じ流儀: 公開 API (WindowSystem/Window) は このインターフェイスのみに依存し、OS 具象 (CsWin32 等) はバックエンドプロジェクトに隔離する。 マルチウィンドウ前提 — Pump は呼び出しスレッドの全ウィンドウのメッセージを処理する。

メソッド

名前型説明
CreateWindow(WindowDesc desc) → IWindowBackendWindowウィンドウを生成する (作成スレッド = メッセージポンプのスレッド)。
Pump() → bool保留メッセージを処理する。生存ウィンドウが 1 つでも残っていれば true。

プロパティ

名前型説明
Namestring (get)バックエンドの人間可読な名前 (例: "Win32")。

IWindowBackendWindow

interface — バックエンドのウィンドウ 1 枚。座標はクライアント領域のピクセル。 入力コールバックはメッセージポンプのスレッドから呼ばれる。

メソッド

名前型説明
SetTitle(string title) → void
SetBounds(int? x, int? y, int? clientWidth, int? clientHeight) → void外枠の位置とクライアントサイズを変更する (null は現状維持)。
Show() → void
Hide() → void
Focus() → void前面化 + キーボードフォーカス。
Close() → void閉じる要求を送る (WM_CLOSE 相当)。
