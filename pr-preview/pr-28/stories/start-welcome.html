Luxel Gallery — 見て、コピーして、アプリを作る

  • 学習ルート
  • コードの保証レベル

Gallery は動く教科書です。説明を読んだら preview を操作し、検証済み Sample Bundle の実ファイルをコピーしてください。

学習ルート

  • GPU が初めて — Grapics で window、device、surface、三角形まで進む
  • 3D アプリを作る — ThreeD で texture、camera、depth、lighting、RenderGraph を組み合わせる
  • 2D アプリを作る — TwoD で path、camera、retained canvas を使う
  • Input / Audio / Resources — Input、Audio、Resourcesでapp runtimeを組む
  • 2D rasterizer の中を読む — Rasterizer Internals で encode、bounds、bin、fine pass を追う

コードの保証レベル

  • Snippet: 既存アプリへ貼る短い断片
  • Block: App Host の接続点へ追加できる機能単位
  • Recipe: 複数 block を組み合わせて build 検証した構成
  • StandaloneProject: .csproj、C#、shader、asset を含む実行可能プロジェクト
  • GalleryOnly: StoryContext など Gallery harness が必要。Source タブだけでは standalone にならない

次に 自分のルートを選ぶ か、Gallery の使い方 を開いてください。
