WindowSystem

class — ウィンドウシステムの公開窓口 (グラフィックデバイスに対するウィンドウ側の窓口)。 バックエンド (Win32 等) を包み、ウィンドウの生成・一覧・メッセージポンプを提供する。 using var windows = new WindowSystem(Luxel.Platform.Windows.Win32WindowBackend.Create()); Window main = windows.CreateWindow(new WindowDesc("App", 800, 600)); var swapchain = device.CreateSurface(main.Handle, (uint)main.Width, (uint)main.Height); while (windows.Pump()) { ...描画して swapchain.Present... }

コンストラクタ

名前型説明
WindowSystem(IWindowBackend backend)

メソッド

名前型説明
CreateWindow(WindowDesc desc) → Windowウィンドウを生成する。メッセージポンプと同じスレッドから呼ぶこと。
Pump() → bool保留メッセージを処理し、閉じたウィンドウを一覧から外す。生存ウィンドウが残っていれば true。
Dispose() → void

プロパティ

名前型説明
Namestring (get)
WindowsIReadOnlyList<Window> (get)生存ウィンドウのスナップショット (閉じたものは Pump で除去済み)。
