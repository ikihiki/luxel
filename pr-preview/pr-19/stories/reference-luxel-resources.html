ResourceSystem

class — リソース管理システム。(型,uri) ノードキャッシュ + 出力型逆引きの再帰オートコンポーズ + 自動リロード。 Source/Step は構築済みインスタンスをコンストラクタ配列 or IResourceSource) / IResourceStep) で登録する。GPU device 等の依存は Step の ctor 引数として呼び出し側 (アプリ) が組み立てて渡す ─ 本システムに DI コンテナは含まれない。

コンストラクタ

名前型説明
ResourceSystem(IReadOnlyList<IResourceSource> sources, IReadOnlyList<IResourceStep> steps)Resource システムを生成。Source/Step はすべて呼び出し側が構築済みインスタンスで渡す。 組込み (FileSource/HttpSource/TexDecoder) も自動登録しない ─ 必要なら ResourceSystemDefaults のヘルパを使うか、直接 new して配列に含める。

ResourceSystemDefaults

class — ResourceSystem のコンストラクタに渡す組込み Source/Step の defaults を提供するヘルパ。 設計: 組込みも DI 経由 (ctor 配列渡し)。ResourceSystem 本体は Source/Step を自動生成しない。 呼び出し側が「何を入れるか」を明示的に組み立てる。 var res = new ResourceSystem( sources: ResourceSystemDefaults.BuiltinSources(assetRoot: "./assets"), steps: ResourceSystemDefaults.BuiltinSteps()); // または追加 Source/Step とスプレッド: var res = new ResourceSystem( sources: [..ResourceSystemDefaults.BuiltinSources(vfs: myVfs), new MyCustomSource()], steps: [..ResourceSystemDefaults.BuiltinSteps(), new MyStep()]);

メソッド

名前型説明
BuiltinSources(string assetRoot, IVirtualFileSystem vfs, HttpClient http) → IResourceSource[]組込み Source (FileSource + HttpSource) の配列を返す。 VFS 未指定なら PhysicalFileSystem を ルートで生成。
BuiltinSteps() → IResourceStep[]組込み Step (TexDecoder) の配列を返す。
