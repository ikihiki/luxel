IWindowContent

interface — ウィンドウに表示する中身。ウィンドウは UI と 1:1 ではない — UI を 1 つ持つ (UiContent)、複数 UI や 3D を合成する、UI を持たない、いずれも実装できる。 Uis は保持する UiHost の列挙 (リモートの UI 一覧/入力ルーティング登録用、空可)。 入力はウィンドウのクライアント座標で WindowHost から転送される。

WindowManager

class — マルチウィンドウの駆動役: WindowSystem + ウィンドウ毎の WindowHost + オフスクリーン UI。 ループは Single) を毎フレーム呼ぶだけ (Drain → Pump → 各窓 Frame → 閉窓の掃除)。 リモート制御は既存 DevTools に統合する: - ウィンドウ一覧/ピクセル = IWindowRemoteHost 実装 → DebugServer の /windows, /winframe - UI (ウィンドウと 1:1 ではない) = UiRegistry に登録 → /trees (Luxel.Trees を 30f 毎に emit) - 操作 = 共有 EngineCommands: window.* (ここで登録) + UI 入力/ui.set (UiRegistry), "ui" index/名前でルーティング)
