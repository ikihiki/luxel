Text

テキスト。既定は 1 行互換 (従来どおり)。/TextAlign を指定するか 内容に \n を含むと TextLayout による複数行レイアウト (折り返し/禁則/整列/Justify) になる。 内容は Func1 で束縛でき、signal 変化で更新される。 色/不透明度/サイズは [UiParam] な Bindable1 フィールド。 状態別の上書きは生成された .When(WidgetState.Hover, color: ...) が状態レイヤで積む。
