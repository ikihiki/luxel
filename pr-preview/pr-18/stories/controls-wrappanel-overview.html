Controls/WrapPanel/Overview

Wrap

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

子を左→右に並べ、幅を超えたら次の行へ折り返すコンテナ (CSS の flex-wrap / WPF WrapPanel 相当)。 行の高さはその行で最も高い子。利用可能幅は制約から取る (無限幅なら Width 指定が必要)。 カードダッシュボード等の可変個パネルの整列向け。
