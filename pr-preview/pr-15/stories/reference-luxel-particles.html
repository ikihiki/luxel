IParticleSimulator

interface — 1 ステップの積分器。バッファ (SoA) と分離してあり、v1 は CPU 実装のみ。 将来 GPU compute シミュレーションを同じ外部 API の下で差し込めるようにするための seam (公開面に CPU 読み戻し前提の API は置かない)。

メソッド

名前型説明
Step(ParticleBuffer buffer, ParticleConfig config, float dt) → void速度/重力/抗力を積分し、寿命切れを前方詰めで除去する (Count を更新)。

ParticleBuffer

class — パーティクルの SoA (Structure-of-Arrays) 固定長バッファ。GC ゼロ (配列は capacity で確保しきり)。 生存パーティクルは [0, Count) に**発生順で連続**して並ぶ (死亡は積分器が前方詰めで除去 — 順序が 変わらないので描画順 = 発生順が安定し golden が決定的)。配列は将来 GPU バッファへそのまま写せる素の float[]。

メソッド

名前型説明
Clear() → void全消去 (再利用)。

ParticleConfig

class — パーティクルシステムの設定。放出方向は BaseAngle ± SpreadRadians (ラジアン、XY 平面)。 Gravity は Y 速度への加速度 (2D 画面座標では +Y が下方向)。Drag は毎秒の速度減衰率。

ParticleValue

struct — パーティクルパラメータの判別共用体 (Effekseer 風)。Const / Range / Curve を 1 型で表し、 Min/Max ペアの ad hoc 増殖を避ける。放出時に固定する量 (寿命/速度/初期サイズ) は Xorshift64@) でスカラー化し、寿命に沿って変える量 (サイズ/色カーブ) は Single) で評価する。 v1 の評価は Const/Range/線形〜曲線補間まで。カーブは ICurve (Luxel.Animation)。 float からの暗黙変換で定数を書ける。
