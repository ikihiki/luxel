ScriptSystem

class — .csx ゲームロジックを World のフェーズループに接続し hot reload する。 安全性が最重要: Reload でコンパイル失敗/実行時例外が出ても**旧 system を動かし続け**、 診断を LastResult/RuntimeException に公開する (ゲームを止めない)。 仕組み: Action) は削除できないので、Single}) で **安定ラッパ system を 1 回だけ登録**し、reload は現在のデリゲート束 (ScriptSystems) を差し替えるだけ。 変更は Changed でフラグに立て、PollReload (フレーム先頭) で 1 回反映する。

PollReload() → voidソースが変わっていれば Reload する (フレーム先頭で呼ぶ — 連続変更を 1 回に畳む)。

class — .csx スクリプトが最後の式で返す「system 登録記述子」。フェーズ別の (World, dt) デリゲートを持つ。 スクリプトは Single}) ヘルパで作る (Systems(update: (w, dt) =&gt; {...}))、 または裸の Action&lt;World, float&gt; を返すと Update 扱い。
