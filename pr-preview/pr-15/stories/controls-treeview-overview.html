Controls/TreeView/Overview

TreeView

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

ツリービュー (展開/折りたたみ + 選択 + 絞り込み)。行 = インデント + シェブロン (子持ちのみ) + ラベル。 葉のクリック = OnSelect (sender-first) 子持ちノード: Tag == null (見出し行) はラベルクリック = 開閉。 Tag != null (選択できるページ等) はラベルクリック = OnSelect + 展開、 開閉はシェブロンのクリック 展開状態は に渡したセットに保持 — 呼び出し側が所有すれば ツリーの作り直し (chrome 再構築等) をまたいで生き残る 選択ハイライトは (Key 一致でアクセント色) が非空なら、Label/SearchText がマッチするノードとその祖先だけを 全展開で表示する (開閉状態は変更しない — クリアで元の表示に戻る)

イベント

名前型説明
OnSelectUiEvent<TreeView, TreeNode>葉ノード選択 (第一引数 = 発火元)。Tag 付き子持ちノードのラベルクリックでも発火する。

パラメータ

名前型説明
RootsIReadOnlyList<TreeNode>ルートノード列。
ExpandedISet<string>展開状態のセット (呼び出し側所有で共有可 — 省略時は自前のセットを遅延生成)。
Selectedstring選択中ノードの Key (ハイライト表示)。
Filterstring絞り込みクエリ (大小無視の部分一致)。signal を渡せばタイプ毎に TreeView だけ再構築される。
