Button

  • Variant (形)
  • Intent (意味色)
  • 使い方
  • API

ボタンは Variant × Intent × 状態 から配色を解決します。未指定のプロパティはテーマ値へフォールバックし、hover/press はトランジション (状態機械) で補間されます。

Variant (形)

Tip

下の実例のすぐ下に StorySource で実際のストーリーソースを出しています (ジェネレーターが焼き込むため、手書きコピーの乖離が起きません)。

[Story("Controls/Button/Variants", Height = 160)]
public static Widget ButtonVariants() => Frame(HStack(8)[
    Button(_ => { }, "Filled"),
    Button(_ => { }, "Tonal", variant: Variant.Tonal),
    Button(_ => { }, "Outline", variant: Variant.Outline),
    Button(_ => { }, "Ghost", variant: Variant.Ghost)]);

Intent (意味色)

使い方

Button(_ => ctx.Log("clicked"), "OK", variant: Variant.Tonal, intent: Intent.Success)

コールバックの第一引数は発火元の Button 自身 (sender-first 規約) です。入門は GettingStarted、状態別スタイルと Tailwind は Docs/Styling へ。

API

角丸背景 + 中央テキスト + クリック。配色は Theme × Variant × Intent × 状態(hover/press/disabled) から 解決し、hover/テーマ変更は recolor のみで部分更新。 スタイルはすべて [UiParam] な Bindable`1 フィールド。状態別の上書きは 生成された .When(WidgetState.Hover, background: ...) が Widget) で積む。 未設定のプロパティはテーマ解決値 (Variant/Intent) にフォールバックする。
