DrawableAttacher

class — AssetMeshRef を持つ全 entity に対して Resources から fragment URI で vertex/index/materials buffer を Load 完了させたうえで DrawMesh / DrawMaterial を attach する。 direct-ref: fragment URI は SceneAssets の内部 index (primitive の登場順) から組み立てる。

メソッド

名前型説明
AttachMesh(World world, SceneAssets assets, ResourceSystem resources, string assetUri) → void

DrawableCollector

class — DRAW-M3: DrawMesh + DrawInstance + DrawMaterial を持つ全 entity を 走査し、RenderGraph に import してから DrawItem のリストとして返す。 Sample 側はこのリストを for-loop で回して push constant を組み立てて Draw を発行するだけでよい。 push constant layout や pipeline binding は shader 依存なので本 collector は関知しない。

メソッド

名前型説明
Collect(World world, RenderGraph rg) → List<DrawItem>DrawMesh + DrawInstance + DrawMaterial 3 点を持つ entity を全て collect。 DrawSkinning があれば Joint handle も取得。

ExtractorSystem

class — Friflo の SystemGroup 風に IRenderExtractor を Schedule に組み込む薄い wrapper。 使い方: var root = ScheduleRoot.Create(world); var rg = new Luxel.RenderGraph.RenderGraph(device); var extractor = new Render3DExtractSystem(world, device); // PreRender phase に Extractor を走らせる system を登録 root.GetChild(Phase.PreRender)?.Add(new ExtractorSystem(extractor, device, frame: 0)); // Render phase で RenderGraph を実行する system を登録 (ユーザ側で BeginPass 等を組む)

コンストラクタ

名前型説明
ExtractorSystem(IRenderExtractor extractor, GpuDevice device, ulong frame)

Render3DExtractSystem

class — GlobalTransform + Color3D + MeshRef を持つ entity を bindless instance バッファへ集約する Friflo BaseSystem (システム標準の 3D 抽出)。 使い方 (Friflo SystemGroup 経由): var root = new SystemRoot(world.Store) { new Render3DExtractSystem(world, device) }; root.Update(default); // Update ごとに Extract 相当が走る gpuBuffer = system.InstanceBuffer; 手動 (SystemGroup を使わない場合): var sys = new Render3DExtractSystem(world, device); sys.Extract(); // 直接呼ぶ ユーザーが独自の抽出 System / ロジックを書きたい場合は本 System を使わず、 同じ InstanceData レイアウトの RenderBuffer`1 を作って書けばよい。

コンストラクタ

名前型説明

メソッド

SceneBuilder

class — AssetDocument を Luxel.Ecs.World へ展開する builder。 direct-ref モデル: index lookup は使わず、AssetNode/AssetMesh/AssetMaterial の直接参照を辿る。 1) Materials → GPU (bindless material array へ) 2) Meshes → GPU (primitive 単位で vertex/index buffer を確保) 3) Nodes を tree walk して Entity 展開 + Parent + LocalTransform + AssetMeshRef/AssetMaterialRef/AssetSkinRef

メソッド

名前型説明
Build(World world, AssetDocument doc, GpuDevice device) → SceneAssets

TransformPropagateSystem

class — LocalTransform + 任意 Parent から GlobalTransform を計算。 深い階層に対応するため複数回反復 (最大 8 回)。 使い方: TransformPropagateSystem.Run(world); var world = entity.GetComponent&lt;GlobalTransform&gt;().Matrix;
