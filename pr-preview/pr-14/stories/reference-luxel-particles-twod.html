ParticleGizmos

class — パーティクルの標準 gizmo (DebugDraw の上に載せる)。エミッタ位置に十字マーカ + 円を描き、 生存数 (Alive) をラベル表示する。パーティクルは ECS エンティティではない (SoA 内部) ので ECS タブに出ない — この gizmo と DevStats が観測の口。OFF 時は割り当てゼロで抜ける。

メソッド

名前型説明
Emitter(ParticleSystem ps, Vector2 pos, uint color, float radius, string kind) → voidにエミッタマーカ (十字 + 円) と alive N ラベルを描く。

フィールド

名前型説明
Emittersstring (const)エミッタ gizmo の既定カテゴリ。

ParticleNode

class — ParticleSystem を RetainedCanvas の 1 ノードへ描く 2D 統合。 ContentColors = true + Int32) で容量を確保しきり、 毎フレーム生存パーティクルのパス列を Content 差し替えで書き込む (Breakout の手法を部品化 — 容量内なら 構造 Rebuild は起きず Segment 再アップロードのみ)。色/サイズは寿命 t で ParticleConfig の カーブから評価する。ワールド座標で描くのでスクロール/ズームは Camera2D 側。
