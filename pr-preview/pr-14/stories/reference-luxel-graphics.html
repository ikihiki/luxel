GpuMemoryKind

enum — ブログの 3 つのメモリ種別。gpuMalloc が返すメモリの性質を選ぶ。

値

名前型説明

DeviceLocalGPU 専用 (DEVICE_LOCAL / DEFAULT)。テクスチャや大きな読み書きバッファ用。
HostCachedCPU からキャッシュ読み出ししやすい (HOST_CACHED / READBACK)。リードバック用。

GpuStage

enum — ステージベースのバリア用のパイプラインステージ。 Vulkan の PipelineStageFlags2 / D3D12 の D3D12_BARRIER_SYNC にバックエンド側で remap する。 ブログの STAGE_COMPUTE / STAGE_PIXEL_SHADER / STAGE_RASTER_COLOR_OUT 等に相当。

値

名前型説明
None
DrawIndirect間接描画/ディスパッチ引数の読み出し。
VertexShader頂点シェーダ (vertex pulling の load を含む)。
PixelShaderピクセル/フラグメントシェーダ。
ComputeShaderコンピュートシェーダ。
ColorOutputカラー出力 (ラスタライザのカラーアタッチメント書き込み)。
DepthStencil深度/ステンシルテストと書き込み。
Copyコピー/転送。
AllGraphicsすべてのグラフィックステージ。
Allすべてのコマンド (最も粗いバリア)。
