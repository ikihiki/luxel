Controls/Toolbar/Overview

Toolbar

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

ツールバー (ADR-0013): 掲載コマンドをボタン列に。disabled はグレー非活性。 クリックはコマンドを実行。登録変更 (Version) で自動追従、 enablement の再評価は Refresh。
