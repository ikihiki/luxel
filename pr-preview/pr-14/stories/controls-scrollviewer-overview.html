Controls/ScrollViewer/Overview

Scroll

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

縦スクロール領域。子を無限高で測ってクリップし、スクロールオフセットを content ノードの transform に反映 (オフセット変更 = transform のみ部分更新)。wheel/キーで操作。

名前型説明
