PhysicsGizmos

class — 物理の標準 gizmo (DebugDraw の上に載せる)。ECS 上の Collider + RigidBody/StaticBody をコライダーワイヤ (箱/球/カプセルは外接ボックス) として最前面オーバーレイに描く。動的/静的/CCD 有効を色分けする。3D はゲームのカメラ (viewProj) を DebugTextDrawer) の WorldToScreen に渡して投影する (2D は恒等)。 各ヘルパは先頭でカテゴリの ON/OFF を判定し、OFF 時は ECS 列挙も割り当ても行わず抜ける (購読者ゼロ規律)。 コライダーワイヤ + CCD 色分け + トリガー色分け (String)) と、接触中ペアの マーカ (String)) を描く。接触マーカは v1 が接触点の詳細位置を公開しない (タスク 04 スコープ) ため、2 entity の中心間midpoint に十字マーカを置く「接触インジケータ」として描く。
