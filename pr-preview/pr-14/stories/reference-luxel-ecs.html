EcsDiagnostics

class — ECS スナップショットの構築 (DevTools 向け)。ゲーム規模 (数百〜数千 entity) で全量シリアライズが 破綻するため、「一覧は軽量 (String) = id + 名前 + アーキタイプ)、詳細は選択したものだけ (Int32))」に分ける。GPU 非依存で単体テスト可能。

メソッド

名前型説明
BuildSummary(IReadOnlyList<World> worlds, string filter) → DiagEcsSummary全 world の軽量サマリ (値なし)。 は名前/Id/component 型名の部分一致 (null/空は全件)。フィルタで絞った結果だけ一覧に載せる — 二正面 UI の DOM/行数爆発を emit 側で抑える。
BuildDetail(IReadOnlyList<World> worlds, int selWorld, int selEntity) → DiagEcs詳細スナップショット (値付き JSON)。選択 ( ≥ 0) があればその 1 entity だけ、 無ければ world ごとに entity 数が FullFallbackThreshold 以下なら全量、超過なら空 (要選択)。
FilterMatch(string name, int id, string[] archetype, string filter) → boolフィルタ一致判定: 空フィルタは全件。名前 / Id 文字列 / component 型名のいずれかに部分一致 (大小無視)。
EntityName(Entity e) → stringDebugName component があればその名、無ければ空文字。
Archetype(Entity e) → string[]所持 component 型名 + tag 型名の列 (アーキタイプ表示用)。

InterpolatedTransform

struct — 固定タイムステップ (FixedUpdate) のシミュレーション結果を描画時に補間するための前/現ステップ TRS。 FixedUpdate 内で Vector3) して「前ステップ位置」と「現ステップ位置」を持ち、 Render 前に TransformInterpolationSystem が Alpha で lerp/slerp して LocalTransform に書き込む。これをやると 60Hz 表示 + 1/60 固定でもガタつかない。

コンストラクタ

名前型説明

メソッド

名前型説明

Teleport(Vector3 position, Quaternion rotation, Vector3 scale) → void前後を同じ TRS に揃える (瞬間移動 — 補間しない)。
Sample(float alpha) → Matrix4x4alpha [0,1] で前→現を補間した行列 (Scale × Rotation × Translation)。

TransformInterpolationSystem

class — 描画補間: InterpolatedTransform を持つ entity の前/現ステップ TRS を 補間係数 alpha [0,1) で lerp/slerp し、LocalTransform に書き込む。 PreRender で 1 回呼ぶ (物理などの PreRender 相当)。 FixedUpdate 側は Vector3) で毎ステップの位置を積むだけでよい。 alpha は GameScene.Alpha (蓄積器の余り / FixedDt) を渡す。 GPU 非依存 — 単体テスト可能。LocalTransform を持たない entity には component を足して書き込む。

メソッド

名前型説明
Run(World world, float alpha) → void登録 entity すべてを alpha で補間して LocalTransform に反映する。

WorldSave

class — ゲーム状態 (ECS World) のセーブ/ロード。Friflo 組み込みの EntitySerializer (component 名 → 値スキーマ、アーキタイプ非依存 = エンジン更新をまたいで安定) を土台に、 バージョン付きラッパを被せる。**文字列 in/out** なのでファイル IO 非依存でテストできる (ファイル層は の IVirtualFileSystem 側で薄く繋ぐ)。 保存対象: 純データ component のみ。GPU ハンドル/観測専用の component は Friflo の [ComponentKey(null)] で除外する (例: DebugName)。復元後に GPU 資源が要る component は「シーン最初のフレームで遅延生成」の既存規約で再構築する。

メソッド

名前型説明
Serialize(World world) → stringWorld を JSON 文字列にする。{ "version":1, "entities":[ ... ] }。
Deserialize(World world, string json, bool clear) → voidJSON 文字列を World へ復元する。=true (既定) は既存 entity を 全消去してから復元。false は Friflo の pid キー upsert (同 pid は上書き、新 pid は追加) で マージする。version 不一致でも throw せず読み進める (migration チェーンは v1 は枠のみ — 将来ここに変換を挟む)。
ClearEntities(World world) → voidWorld の全 entity を削除する (復元前のクリア用)。
