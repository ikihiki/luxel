AppWindow

class — ウィンドウ + 保持型キャンバス + UiHost + GPU スワップチェーン提示を束ねる実行ループ。 framebuffer 幅を 64 の倍数にパディングして確保 (D3D12 の 256B 行整列を充足)、可視領域のみ present。

コンストラクタ

名前型説明
AppWindow(GpuDevice device, VectorFont font, int width, int height, string title)

メソッド

名前型説明
SetRoot(Widget root) → void
Close() → voidウィンドウに閉じ要求を送る。Run は次の Pump でループを抜ける (UI イベントハンドラ内から「終了」を実現するのに使う)。
SimulateKey(ushort vk) → boolキーを TSF→UI 層の順に通す (擬似自動テスト用)。TIP が消費したら true。
SimulateText(string text) → voidテキストを UI 層へ直接入力する (擬似自動テスト用, 非 IME ASCII 相当)。
Foreground() → voidウィンドウを前面化 (SendInput の宛先にするため)。
ActivateJapaneseIme() → void日本語 IME を有効化し ひらがな/ローマ字入力モードにする (実変換 E2E テスト用)。
SendKeyStroke(ushort vk) → void実キーを OS 入力キューへ注入 (SendInput) → アクティブ IME が処理する。
Step(int frames) → voidメッセージを処理しつつ n フレーム描画 (閉じない)。IME 非同期処理を進める。
ForwardKey(ushort vk) → boolキーを TSF(TIP) へ注入して操作する (ブラウザ等のリモート入力 → OS IME 変換)。 前面ウィンドウ不要 (ITfKeystrokeMgr 直送)。TIP が消費しなければ UI 層へフォールバック。
Run() → void対話実行 (閉じるまでループ)。
RunFrames(int frames) → voidn フレーム回して閉じる (スモーク用)。
Dispose() → void

Win32InputSource

class — Win32 の keyboard / mouse event を IInputSource として InputBus に流す実装。 AppWindow が本ソースをインスタンス化し、Win32Window の callback から差分イベントを注入する。 portable WindowKey → KeyCode のマッピングは内部対応表で行う。
