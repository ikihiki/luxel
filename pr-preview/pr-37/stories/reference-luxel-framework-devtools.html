DevToolsRuntime

class — DevTools フロントエンドのライフサイクルを host に載せる hosted service。listener を先に作って エンジン診断を購読させ (これで String) が true になる)、 選択に応じて DebugServer / DevToolsApp を起動する。

Dispose() → void

プロパティ

名前型説明
BrowserUrlstring (get)ブラウザ版 DebugServer の URL (起動時のみ、なければ null)。ゲームがログに出すのに使う。

IFramePublisher

interface — ゲームの提示フレームを DevTools のライブビューへ配信する口 (Q05 E)。ゲームは提示ループで Int32) を呼ぶだけでよい (どのフロントエンドが購読しているかは意識しない)。 購読者ゼロなら String) 判定だけで即 return する zero-cost。

LuxelHostDevToolsExtensions

class — LuxelHostBuilder に DevTools を結線する拡張 (Q05 E)。Gallery の Program.cs で手書き していた定型 (listener 生成 + DebugServer 起動 + EngineCommands 配線 + 内蔵版起動) を 1 行に集約する。

メソッド

名前型説明
WithDevTools(LuxelHostBuilder builder, DevToolsOptions options) → LuxelHostBuilderDevTools をオプトインで結線する。 でブラウザ版/内蔵版を選択 (既定は両方 off)。 結線されるもの: DevToolsListener (エンジン診断を購読 → 以降 emit が有効化)、 指定時 DebugServer (ブラウザ) / DevToolsApp (内蔵ウィンドウ)、 および IFramePublisher (提示ループが呼ぶフレーム配信口)。 ライフサイクルは IHostedService として host に載るので、host.Start() で起動し host.StopAsync() で破棄される。
