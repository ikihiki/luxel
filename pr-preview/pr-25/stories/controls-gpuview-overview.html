GpuView

IGpuScene の描画結果を表示する widget — 3D/GPU 描画結果をストーリー/docs に載せる器。 GpuView(320, 240, new TriangleScene()) // 毎フレーム Render (アニメ) GpuView(320, 240, new TexturedScene(ctx.Resources), animated: false) // 1 回だけ Render (静的) 結果は image プリミティブの 1 ノード (CPU 読み戻しなし) — 同一 device/queue なので submit 順で 同期される。シーンの寿命は realize スコープが所有 (ストーリー切替 = SetRoot 破棄で Dispose)。
