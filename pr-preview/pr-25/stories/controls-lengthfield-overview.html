Controls/LengthField/Overview

LengthField

Luxel.Controls のコントロール API です。コンストラクタ引数・イベント・パラメータは [UiComponent] のソースと XML doc コメントから生成されます。

Length の入力コンボ: 数値 TextField + 単位 Select (px/%/em/vw/vh) を 1 つのコントロールとして束ねる (Gallery の Width/Height 等 "length" prop エディタ)。 双方向同期は ColorPicker と同じ「_sync フラグ + Signal の等値スキップ」で循環収束させる。 空欄の間は値を書かない (最後の有効値を保持)。
